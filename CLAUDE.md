# CLAUDE.md

Personal portfolio site. Next.js (App Router) + TypeScript + Tailwind CSS v4, static export, deployed to GitHub Pages.

## Read before any task

- `BRIEF.md` — what we are building and for whom
- `DESIGN.md` — design tokens and hard rules (must follow)
- `AGENTS.md` — Next.js 16 notes, auto-generated by `next dev` (do not edit). Check `node_modules/next/dist/docs/` before using any Next.js API.
- `GLOSSARY.md` and `docs/adr/` (if present) — shared vocabulary and past decisions from `/grill-with-docs`

If a request conflicts with BRIEF.md or DESIGN.md, stop and say so before writing code.

## About the developer (important)

- I am new to React. This project is how I learn.
- Explain in **Thai**. Keep code, comments, commit messages and site copy in **English**.
- For every new or changed component, give a short explanation: what it does, its props, and which React concept it uses (e.g. props, state, `"use client"`, mapping over arrays).
- Prefer simple, readable code over clever code. No abstractions until there are at least 2 real uses.

## Working rules

- Small changes. One ticket = one focused diff I can read in a few minutes.
- I read every diff. Do not commit, push or install packages without asking me first.
- Do not invent content (names, projects, links, numbers). Use `[[TODO: ...]]` placeholders.
- Before saying a task is done, run `npm test`, `npm run lint` and `npm run build`, and confirm they pass.

## Static export constraints

`next.config.ts` uses `output: 'export'` and `images: { unoptimized: true }`. No `basePath` (repo is `<username>.github.io`).

Not allowed (they need a server): API routes, Server Actions, middleware, ISR/revalidate, dynamic routes without `generateStaticParams`, `cookies()`/`headers()`.

## Design rules (summary — full rules in DESIGN.md)

- Only use tokens defined in `app/globals.css` `@theme`. No arbitrary values like `text-[#123456]` or `p-[13px]`.
- No gradients. No emoji as icons. Icons from `lucide-react` only, except the GitHub logo (see DESIGN.md §9).
- Base components live in `components/ui/` and are built only from tokens. Sections compose them.

## Project structure

```
app/            layout.tsx, page.tsx, globals.css (tokens), styleguide/
components/ui/  Button, Card, Tag, Navbar, Section, Container
components/     Hero, About, Projects, Contact, Footer
content/        projects.ts (project data — add projects here only)
public/         resume.pdf, images
```

## Commands

- `npm run dev` — local dev server
- `npm run build` — static build into `out/`
- `npm run lint`
- `npm test` — run tests once (Vitest, not watch mode)
